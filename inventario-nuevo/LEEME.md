# Inventario nuevo (fotos originales)

Esta carpeta es para subir el inventario nuevo **con las fotos originales, sin tocar**.
Claude las convierte después a WebP (640 y 1200 px) para el sitio; los originales se quedan aquí tal cual.

## Cómo subir

1. Entra a la carpeta: https://github.com/n28mink/city-cars-houstontx/tree/main/inventario-nuevo
2. Toca **Add file → Upload files** (o usa directo https://github.com/n28mink/city-cars-houstontx/upload/main/inventario-nuevo).
3. Arrastra las carpetas de cada vehículo y toca **Commit changes**.

Límites de GitHub en el navegador: hasta 100 archivos por vez y 25 MB por archivo. Si son muchas, súbelas en tandas.

## Cómo ordenar

Una carpeta por vehículo, con el año, la marca, el modelo y el color en el nombre:

```
inventario-nuevo/
  2022-chevrolet-tahoe-lt-negro/
    1.jpg
    2.jpg
    3.jpg
    datos.txt        (opcional)
  2021-ford-f150-xlt-blanco/
    ...
  inventario.csv     (opcional: una fila por vehículo)
```

El orden de las fotos lo da el nombre del archivo: la `1` es la principal.

## Qué datos ayudan (todos opcionales)

Año, marca, modelo, color, millas, tipo (troca, SUV o sedán), pasajeros, tracción (solo si la foto lo confirma) y equipamiento visible.
Lo que falte se marca como "por confirmar con el dealer". **Nunca** escribas precios, inicial, mensualidad, APR ni plazos.

## Antes de subir

- Esta carpeta y el repositorio son **públicos**: cualquiera puede ver estas fotos en GitHub.
- Revisa que las fotos no muestren montos, precios ni letreros de "FINANCIADO", ni placas legibles ni caras.
